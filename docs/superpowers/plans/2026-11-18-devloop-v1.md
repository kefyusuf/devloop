# devloop v1 Implementation Plan (v2 — inceleme revizyonu)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Revizyon geçmişi:** v1 (2026-11-18) bağımsız inceleme ile gözden geçirildi; P0 bulguları (gate enforcement, repo bağlamı, bütçe takibi, store dayanıklılığı, izolasyon, hafıza bağlantısı) ve P1 bulguları (deterministik aday ID, test-implementasyon çelişkileri) bu sürümde giderildi. Yapı, incelemenin önerdiği 4 doğrulama aşamasına göre gruplandı. Spec karşılığı: `2026-11-18-ai-dev-loop-design.md` Revizyon 1 (A1–A6).

**Goal:** Spec'teki dikey dilim (D5): görev listesinden görev al → GeneratorBackend diff üretir → fail-closed deterministik gate'ler + tek LLM reviewer → doğrulanmış artifact'e bağlı PR → append-only verdict store + insan-onaylı L1 hafıza — tamamı değişmez kural testleriyle kanıtlı tek CLI.

**Architecture:** Modüler monolit (D6): TypeScript'te tek süreç, tipli kontratlar; Verdict Store append-only JSONL (tek yazıcı, nedensel doğrulama, idempotency). Local-first CLI kabuk (D4). `LlmGateway` (çıkarım) ile `GeneratorBackend` (kod üreten agent) ayrımı (A1) — v1 backend'i repo bağlamı okuyan LLM implementasyonu. V1 güvenlik sınırı: **trusted repositories only** (A5).

**Tech Stack:** TypeScript 5 (ESM), Node ≥20, vitest, zod, commander, yaml. LLM erişimi ham `fetch`.

**Spec:** `docs/superpowers/specs/2026-11-18-ai-dev-loop-design.md` (D1–D6 + Revizyon 1; executor ikisini de okumalı)

## Global Constraints

- **Fail-closed (A2):** gate `fail` veya `error` → PR yok; yetkisiz `skipped` → fail; politikada olup eksik stage → `PipelineConfigError`. `PASS` yalnız tüm zorunlu gate'lerin gerçek `pass`'i ile oluşur.
- **Trusted repositories only (A5):** worktree kaynak izolasyonudur, sandbox değildir. Komutlar sabit executable + timeout + shell yok. `applyArtifact` canonicalization + symlink denetimi.
- **Append-only + bütünlük (A3):** tek yazıcı; `validateChain` nedensel referansları doğrular; `idempotencyKey` ile tekrar yazım engeli; bozuk satır okumada atılır (testli kural), yazmada katı şema.
- **Hafıza hedefi (A4):** dersler `targetComponent` ile ayrılır; reviewer dersi generator'a akmaz; aday ID deterministik; `active` yalnız insan onayıyla.
- Bütçe: `BudgetedGateway` gerçek kullanım üzerinden; aşım → `RunAborted(budget)`.
- Hedef repo'ya asla main'e yazma — `git worktree` + feature branch.
- API anahtarları yalnız env (`ANTHROPIC_API_KEY`); süreçlere gereksiz sırlar aktarılmaz.
- Testler gerçek LLM'e çarpmaz (`DEVLOOP_SMOKE=1` hariç); en az bir gerçek araç zinciri (tsc) entegrasyon testi zorunlu.
- **Değişmez kural sözleşmesi:** spec A6 tablosundaki 8 değişmzenin her biri Task 15'te testle kanıtlanır.

  maxIterations: z.number().int().positive(),
  budgetUsd: z.number().positive(),
  wallClockMinutes: z.number().positive(),
  risk: z.object({ weights: Weights }),
  llm: Llm,
});
export type Policy = z.infer<typeof Policy>;

export interface DevloopConfig { apiKeyEnvVar: string }
const DEFAULT_POLICY: Policy = {
  version: 1, gates: ['risk-triage', 'static-gates', 'tests', 'secret-scan'],
  advisory: ['llm-reviewer', 'mutation-testing'], authorizedSkips: ['mutation-testing'],
  maxFixTours: 3, maxIterations: 10, budgetUsd: 2.0, wallClockMinutes: 30,
  risk: { weights: { diffSize: 0.3, testDiff: 0.5, scopePaths: 0.2 } },
  llm: { provider: 'anthropic', model: 'claude-sonnet-4-5', fallbackModel: 'claude-haiku-3-5',
    maxTokens: 8192, costPer1kInput: 0.003, costPer1kOutput: 0.015 },
};

export function loadConfig(dir: string): { config: DevloopConfig; policy: Policy } {
  const path = join(dir, 'policy.yaml');
  const policy = existsSync(path) ? Policy.parse(parse(readFileSync(path, 'utf8'))) : DEFAULT_POLICY;

export const FindingSchema = z.object({

  evidence: z.object({ file: z.string(), line: z.number().int().optional() }),
  suggestion: z.string().optional(),
});
export type Finding = z.infer<typeof FindingSchema>;

export const TaskSpecSchema = z.object({
  id: z.string(), description: z.string(),
  acceptanceCriteria: z.array(z.string()).min(1),
  filesScope: z.array(z.string()).default([]),
});

export const ArtifactSchema = z.object({
  diff: z.string(), intent: z.string(),

  files: z.array(z.object({ path: z.string(), content: z.string() })),
});
export type Artifact = z.infer<typeof ArtifactSchema>;

`src/contracts/events.ts`:
```ts
import { z } from 'zod';
import { randomUUID } from 'node:crypto';
import { FindingSchema, TaskSpecSchema, ArtifactSchema, DecisionReason } from './schemas.js';

const EnvBase = z.object({
  event_id: z.string(), schema_version: z.number(), ts: z.string(),
  run_id: z.string(), task_id: z.string(), actor: z.string(),
  idempotencyKey: z.string().optional(),
});

const P = {
  RunStarted: z.object({ configSnapshot: z.record(z.unknown()) }),
  TaskPicked: z.object({ taskSpec: TaskSpecSchema }),
  ArtifactProduced: z.object({ artifact: ArtifactSchema, parentTaskEventId: z.string() }),
  RiskScored: z.object({ score: z.number().min(0).max(100), signals: z.record(z.number()), policyVersion: z.string(), parentArtifactEventId: z.string() }),
  FindingEmitted: z.object({ finding: FindingSchema, parentArtifactEventId: z.string(), parentRiskEventId: z.string().optional() }),
  StageVerdict: z.object({ stage: z.string(), status: z.enum(['pass', 'fail', 'error', 'skipped']), durationMs: z.number(), errorMessage: z.string().optional() }),
  HumanDecision: z.object({ decision: z.enum(['accept', 'reject']), reason: DecisionReason, note: z.string().optional(), parentFindingEventIds: z.array(z.string()) }),
  PRCreated: z.object({ url: z.string().nullable(), title: z.string(), commitSha: z.string().nullable(), diffDigest: z.string() }),
  TaskBlocked: z.object({ reason: z.string(), parentArtifactEventId: z.string().optional() }),
  LessonLearned: z.object({
    lessonId: z.string(), rule: z.string(), scope: z.string(), confidence: z.number().min(0).max(1),
    status: z.enum(['candidate', 'active', 'retired']),
    targetComponent: z.enum(['generator', 'reviewer']),
    parentDecisionEventIds: z.array(z.string()), parentLessonEventId: z.string().optional(),
  }),
  EvalRun: z.object({ score: z.number(), comparison: z.record(z.unknown()) }),
  RunAborted: z.object({ reason: z.enum(['budget', 'kill', 'panic', 'wallclock']) }),
} as const;

export type EventType = keyof typeof P;
export type EventPayloadMap = { [K in EventType]: z.infer<(typeof P)[K]> };

function branch<K extends EventType>(type: K) {
  return EnvBase.extend({ type: z.literal(type), payload: P[type] });
}
export const DevloopEventSchema = z.union([
  branch('RunStarted'), branch('TaskPicked'), branch('ArtifactProduced'), branch('RiskScored'),
  branch('FindingEmitted'), branch('StageVerdict'), branch('HumanDecision'), branch('PRCreated'),
  branch('TaskBlocked'), branch('LessonLearned'), branch('EvalRun'), branch('RunAborted'),
]);
export type DevloopEvent = z.infer<typeof DevloopEventSchema>;

export function makeEnvelope(runId: string, taskId: string, actor: string, idempotencyKey?: string) {
  return {
    event_id: randomUUID(), schema_version: 1, ts: new Date().toISOString(),
    run_id: runId, task_id: taskId, actor, ...(idempotencyKey ? { idempotencyKey } : {}),
  };
}
export { P as EventPayloads };
```

import { appendFileSync, existsSync, readFileSync, mkdirSync } from 'node:fs';
import { dirname } from 'node:path';
import { DevloopEventSchema, makeEnvelope, type DevloopEvent, type EventPayloadMap, type EventType } from '../contracts/events.js';

export class VerdictStore {
  constructor(private readonly logPath: string) {}

  async append<K extends EventType>(
    type: K, runId: string, taskId: string, actor: string,
    payload: EventPayloadMap[K], idempotencyKey?: string,
  ): Promise<DevloopEvent> {
    if (idempotencyKey) {
      const dup = this.readAll().find((e) => e.idempotencyKey === idempotencyKey);
      if (dup) return dup;
    }
    const candidate = { ...makeEnvelope(runId, taskId, actor, idempotencyKey), type, payload };
    const ev = DevloopEventSchema.parse(candidate); // yazmada katı
    mkdirSync(dirname(this.logPath), { recursive: true });
    appendFileSync(this.logPath, JSON.stringify(ev) + '\n', 'utf8');
    return ev;
  }

  readAll(): DevloopEvent[] {
    if (!existsSync(this.logPath)) return [];
    const out: DevloopEvent[] = [];
    for (const line of readFileSync(this.logPath, 'utf8').split('\n')) {
      if (!line.trim()) continue;
      let raw: unknown;
      try { raw = JSON.parse(line); } catch { continue; } // bozuk satır atılır — throw yok (A3)
      const parsed = DevloopEventSchema.safeParse(raw);
      if (parsed.success) out.push(parsed.data);
    }
    return out;
  }

  query(f: { runId?: string; taskId?: string; type?: EventType }): DevloopEvent[] {
    return this.readAll().filter((e) =>
      (f.runId === undefined || e.run_id === f.runId) &&
      (f.taskId === undefined || e.task_id === f.taskId) &&
      (f.type === undefined || e.type === f.type));
  }
}

/** Nedensel bütünlük (A3): tüm parent*EventId referansları gerçek event'lere mi işaret ediyor? */
export function validateChain(events: DevloopEvent[]): { ok: boolean; errors: string[] } {
  const ids = new Set(events.map((e) => e.event_id));
  const errors: string[] = [];
  const add = (child: string, parent: unknown) => {
    if (typeof parent === 'string' && parent.length > 0 && !ids.has(parent)) {
      errors.push(`${child.slice(0, 8)} → eksik parent ${parent.slice(0, 8)}`);
    }
  };
  const arrayFields = ['parentFindingEventIds', 'parentDecisionEventIds'];
  const scalarFields = ['parentTaskEventId', 'parentArtifactEventId', 'parentRiskEventId', 'parentLessonEventId'];
  for (const e of events) {
    const p = e.payload as Record<string, unknown>;
    for (const k of scalarFields) add(e.event_id, p[k]);
    for (const k of arrayFields) {
      if (Array.isArray(p[k])) for (const x of p[k] as unknown[]) add(e.event_id, x);
    }
  }
  return { ok: errors.length === 0, errors };
}

import type { ReviewStage, ReviewContext, StageResult } from '../../contracts/review.js';
import type { Artifact, Finding } from '../../contracts/schemas.js';
import { randomUUID } from 'node:crypto';
import type { Policy } from '../../config/config.js';

const TEST_FILE_RE = /(^|\/)(tests?|__tests__)\/|\.test\.|\.spec\./;

export function computeRisk(artifact: Artifact, policy: Policy): { score: number; signals: Record<string, number> } {
  const diffLines = artifact.diff.split('\n').length;
  const diffSize = Math.min(1, diffLines / 500);
  const testDiff = artifact.files.some((f) => TEST_FILE_RE.test(f.path)) ? 1 : 0;
  const scopePaths = artifact.files.some((f) => /(^|\/)(src|lib)\//.test(f.path)) ? 1 : 0;
  const w = policy.risk.weights;
  const score = Math.round(100 * Math.min(1, w.diffSize * diffSize + w.testDiff * testDiff + w.scopePaths * scopePaths));
  return { score, signals: { diffSize: Number(diffSize.toFixed(3)), testDiff, scopePaths } };
}

export class RiskTriageStage implements ReviewStage {
  readonly name = 'risk-triage';
  readonly kind = 'gate' as const;
  constructor(private readonly policy: Policy) {}

  async evaluate(ctx: ReviewContext): Promise<StageResult> {
    const t0 = Date.now();
    const { score, signals } = computeRisk(ctx.artifact, this.policy);
    ctx.riskScore = score;
    ctx.riskSignals = signals;
    const findings: Finding[] = signals.testDiff === 1 ? [{
      id: randomUUID(), stage: this.name, category: 'test-diff', severity: 'required', confidence: 1,
      evidence: { file: ctx.artifact.files.find((f) => TEST_FILE_RE.test(f.path))!.path },
      suggestion: 'Test değişiklikleri önce review edilmeli; assert değişimleri kırık davranışı gizleyebilir.',
    }] : [];
    return { status: 'pass', findings, durationMs: Date.now() - t0 };
  }
}

import { randomUUID } from 'node:crypto';
import { relative, isAbsolute } from 'node:path';
import type { Finding } from '../../contracts/schemas.js';

function rel(p: string): string { return isAbsolute(p) ? relative(process.cwd(), p).replaceAll('\\', '/') : p; }
function f(partial: Omit<Finding, 'id'>): Finding { return { id: randomUUID(), ...partial }; }

type EslintFile = { filePath: string; messages: Array<{ ruleId: string | null; line: number; message: string; severity: 1 | 2 }> };

export function parseEslintJson(raw: string): Finding[] {
  let files: EslintFile[];
  try { files = JSON.parse(raw) as EslintFile[]; } catch { return []; }
  if (!Array.isArray(files)) return [];
  return files.flatMap((file) => file.messages.map((m) => f({
    stage: 'static-gates', category: 'lint',
    severity: m.severity === 2 ? 'required' : 'optional',
    confidence: 1, evidence: { file: rel(file.filePath), line: m.line },
    suggestion: `eslint:${m.ruleId ?? 'parse'} — ${m.message}`,
  })));
}

export function parseTscOutput(raw: string): Finding[] {
  return raw.split('\n').flatMap((line) => {
    const m = /^(.+?)\((\d+),\d+\):\s+error\s+(TS\d+):\s+(.+)$/.exec(line.trim());
    if (!m) return [];
    return [f({ stage: 'static-gates', category: 'typecheck', severity: 'critical', confidence: 1,
      evidence: { file: rel(m[1]), line: Number(m[2]) }, suggestion: `tsc ${m[3]}: ${m[4]}` })];
  });
}

export function parseVitestOutput(summary: string, fullOutput: string): TestRunResult {
  const m = /(\d+)\s+failed/.exec(summary);
  const failed = m ? Number(m[1]) : 0;
  const findings: Finding[] = failed > 0 ? [f({
    stage: 'tests', category: 'tests', severity: 'critical', confidence: 1,
    evidence: { file: '(test-output)' }, suggestion: `${failed} test başarısız — çıktı: ${fullOutput.slice(0, 2000)}`,
  })] : [];
  return { passed: failed === 0 && /passed|no tests/i.test(summary), output: fullOutput, findings };
}

import type { StackAdapter, TestRunResult } from '../types.js';

import { parseEslintJson, parseTscOutput, parseVitestOutput } from './parsers.js';

const run = promisify(execFile);
const SPAWN = { timeout: 120_000, maxBuffer: 10 * 1024 * 1024, shell: false } as const; // A5: sabit executable, shell yok

async function safeStdout(cmd: string, args: string[], cwd: string): Promise<string | undefined> {
  try { return (await run(cmd, args, { cwd, ...SPAWN })).stdout; }
  catch (e) { return (e as { stdout?: string }).stdout; }

  readonly id = 'typescript';

  async lint(repoPath: string): Promise<Finding[]> {

  async typecheck(repoPath: string): Promise<Finding[]> {

`src/pipeline/pipeline.ts`:
```ts
import type { ReviewStage, ReviewContext, StageResult } from '../contracts/review.js';
import type { Finding } from '../contracts/schemas.js';
import { SEVERITY_ORDER } from '../contracts/schemas.js';
import type { Policy } from '../config/config.js';

export interface PipelineResult {
  verdicts: Array<{ stage: string; status: StageResult['status']; durationMs: number }>;
  findings: Finding[];
  gateFailed: string | null;
  passed: boolean;
}
export class PipelineConfigError extends Error {}

const rank = (s: Finding['severity']) => SEVERITY_ORDER.indexOf(s);

export class ReviewPipeline {
  constructor(private readonly stages: ReviewStage[], private readonly policy: Policy) {}

  private ordered(): ReviewStage[] {
    const byName = new Map(this.stages.map((s) => [s.name, s]));
    const wanted = [...this.policy.gates, ...this.policy.advisory];
    const missing = wanted.filter((n) => !byName.has(n));
    if (missing.length > 0) throw new PipelineConfigError(`Politikada olup implementasyonu olmayan stage'ler: ${missing.join(', ')}`); // A2 fail-closed
    return wanted.map((n) => byName.get(n)!);
  }

  async run(ctx: ReviewContext): Promise<PipelineResult> {
    const verdicts: PipelineResult['verdicts'] = [];
    const allFindings: Finding[] = [];
    let gateFailed: string | null = null;
    for (const s of this.ordered()) {
      let res: StageResult;
      try { res = await s.evaluate(ctx); }
      catch (e) { res = { status: 'error', findings: [], durationMs: 0, errorMessage: String(e) }; }
      verdicts.push({ stage: s.name, status: res.status, durationMs: res.durationMs });
      allFindings.push(...res.findings);
      if (s.kind === 'gate') {
        const unauthorizedSkip = res.status === 'skipped' && !this.policy.authorizedSkips.includes(s.name);
        if (res.status === 'fail' || res.status === 'error' || unauthorizedSkip) { gateFailed = s.name; break; }
      }
    }
    return { verdicts, findings: this.dedupe(allFindings), gateFailed, passed: gateFailed === null };
  }

  /** Aynı file+line+category → tek bulgu; en şiddetli birebir korunur. Farklı kategori/stage çelişkisi korunur (§5.2.4). */
  private dedupe(findings: Finding[]): Finding[] {
    const byKey = new Map<string, Finding>();
    for (const f of findings) {
      const key = `${f.evidence.file}:${f.evidence.line ?? '-'}:${f.category}`;
      const cur = byKey.get(key);
      if (!cur || rank(f.severity) < rank(cur.severity)) byKey.set(key, f);
    }
    return [...byKey.values()].sort((a, b) => rank(a.severity) - rank(b.severity));
  }
}
```

import { z } from 'zod';
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, relative, sep } from 'node:path';
import type { LlmGateway } from '../gateway/gateway.js';
import type { Artifact, Finding, TaskSpec } from '../contracts/schemas.js';
import { ArtifactSchema } from '../contracts/schemas.js';

export interface LessonsProvider { contextFor(task: TaskSpec): string }

export interface GenerationContext {
  repoPath: string; repoTree: string; repoFiles: Array<{ path: string; content: string }>;
  lessons: string; feedback: Finding[];
}
export interface GeneratorBackend {
  readonly id: string;
  generate(task: TaskSpec, ctx: GenerationContext): Promise<Artifact>;
}

const SKIP_DIRS = new Set(['node_modules', '.git', '.devloop', 'dist', 'build', 'coverage']);

export const REPO_LIMITS = { maxFiles: 40, maxBytesPerFile: 20_000, maxTotalBytes: 120_000 } as const;

export function readRepoContext(
  repoPath: string, filesScope: string[],
  limits: { maxFiles: number; maxBytesPerFile: number; maxTotalBytes: number } = REPO_LIMITS,
): Pick<GenerationContext, 'repoPath' | 'repoTree' | 'repoFiles'> {
  const files: Array<{ path: string; content: string }> = [];
  let total = 0;
  const walk = (dir: string) => {
    if (files.length >= limits.maxFiles || total >= limits.maxTotalBytes) return;
    for (const entry of readdirSync(dir, { withFileTypes: true })) {
      const full = join(dir, entry.name);
      const relPath = relative(repoPath, full).replaceAll(sep, '/');
      if (entry.isDirectory()) { if (!SKIP_DIRS.has(entry.name)) walk(full); continue; }
      if (!entry.isFile() || !/\.(ts|tsx|js|jsx|json|md|ya?ml)$/.test(entry.name)) continue;
      const inScope = filesScope.length === 0 || filesScope.some((s) => relPath === s || relPath.startsWith(s.endsWith('/') ? s : s + '/'));
      if (!inScope) continue;
      const stat = statSync(full);
      if (stat.size > limits.maxBytesPerFile || total + stat.size > limits.maxTotalBytes) continue;
      files.push({ path: relPath, content: readFileSync(full, 'utf8') });
      total += stat.size;
      if (files.length >= limits.maxFiles || total >= limits.maxTotalBytes) return;
    }
  };
  walk(repoPath);
  return { repoPath, repoTree: files.map((f) => f.path).join('\n'), repoFiles: files };
}

const GenOutput = z.object({

  rejectedAlternatives: z.array(z.string()),

});

import { mkdirSync, writeFileSync, realpathSync, lstatSync, existsSync } from 'node:fs';
import { dirname, isAbsolute, join, relative, resolve } from 'node:path';
import type { Artifact } from '../contracts/schemas.js';

/** A5: canonicalization + `..` reddi + symlink denetimi. Repo dışına yazma yok. */
export async function applyArtifact(repoPath: string, artifact: Artifact): Promise<void> {
  const root = realpathSync(resolve(repoPath));
  for (const file of artifact.files) {
    const rel = file.path.replaceAll('\\', '/');
    const target = resolve(root, rel);
    const relFromRoot = relative(root, target);
    if (relFromRoot.startsWith('..') || isAbsolute(relFromRoot)) {
      throw new Error(`Yol kaçışı reddedildi: ${file.path}`);
    }
    const parent = dirname(target);
    let probe = parent;
    while (probe !== root && !existsSync(probe)) probe = dirname(probe); // var olan en yakın ata
    if (existsSync(probe)) {
      const st = lstatSync(probe);
      if (st.isSymbolicLink()) throw new Error(`Sembolik bağ hedefi reddedildi: ${file.path}`);
    }
    mkdirSync(parent, { recursive: true });
    writeFileSync(target, file.content, 'utf8');
  }
}

import type { LessonsProvider } from '../generator/generator.js';
import type { EventPayloadMap } from '../contracts/events.js';
import type { DevloopEvent } from '../contracts/events.js';
import type { TaskSpec } from '../contracts/schemas.js';

type Lesson = EventPayloadMap['LessonLearned'];

export class LessonMemory implements LessonsProvider {
  constructor(private readonly store: VerdictStore, private readonly lessonsFile: string) {}

  private latest(): Map<string, Lesson> {
    const map = new Map<string, Lesson>();
    for (const ev of this.store.query({ type: 'LessonLearned' })) map.set(ev.payload.lessonId, ev.payload as Lesson);
    return map;
  }
  private active(target: 'generator' | 'reviewer'): Lesson[] {
    return [...this.latest().values()].filter((l) => l.status === 'active' && l.targetComponent === target);
  }

  contextFor(task: TaskSpec): string {
    const words = `${task.description} ${task.acceptanceCriteria.join(' ')}`.toLowerCase().split(/\W+/).filter((w) => w.length > 3);
    const lessons = this.active('generator');
    const relevant = lessons.filter((l) => words.some((w) => `${l.rule} ${l.scope}`.toLowerCase().includes(w)));
    const chosen = relevant.length > 0 ? relevant : lessons.slice(0, 5);
    return chosen.length === 0 ? 'Aktif ders yok.' : chosen.map((l) => `- [${l.scope}] ${l.rule}`).join('\n');
  }

  reviewerContext(): string {
    const lessons = this.active('reviewer');
    return lessons.length === 0 ? 'Reviewer dersi yok.' : lessons.map((l) => `- [${l.scope}] ${l.rule}`).join('\n');
  }

  render(): void {
    const g = this.active('generator');
    const r = this.active('reviewer');
    const lines = ['# devloop aktif dersler (otomatik üretilir — elle düzenlemeyin)', '', '## Generator', ...(g.length ? g.map((l) => `- [${l.scope}] ${l.rule}`) : ['(yok)']), '', '## Reviewer', ...(r.length ? r.map((l) => `- [${l.scope}] ${l.rule}`) : ['(yok)'])];
    writeFileSync(this.lessonsFile, lines.join('\n') + '\n', 'utf8');
  }

  async markRetired(lessonId: string, decisionEventIds: string[]): Promise<DevloopEvent> {
    const prev = this.latest().get(lessonId);
    if (!prev) throw new Error(`Ders bulunamadı: ${lessonId}`);

      lessonId, rule: prev.rule, scope: prev.scope, confidence: prev.confidence,
      status: 'retired', targetComponent: prev.targetComponent, parentDecisionEventIds: decisionEventIds,
    });
    this.render();
    return ev;

    return this.store.append('LessonLearned', 'learning', payload.lessonId, 'learning', payload);

```ts
import { randomUUID } from 'node:crypto';
import { createHash } from 'node:crypto';
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
import { existsSync, readFileSync, rmSync } from 'node:fs';
import { join } from 'node:path';
import type { VerdictStore } from '../store/store.js';
import type { GeneratorBackend } from '../generator/generator.js';
import { applyArtifact } from '../generator/apply.js';
import type { ReviewPipeline, PipelineResult } from '../pipeline/pipeline.js';
import type { LlmGateway, TokenUsage } from '../gateway/gateway.js';
import type { Policy } from '../config/config.js';
import type { ReviewContext } from '../contracts/review.js';
import { TaskSpecSchema, type Artifact, type Finding } from '../contracts/schemas.js';
import type { PrReporter } from '../shell/pr.js';

const runGit = promisify(execFile);

export interface OrchestratorDeps {
  store: VerdictStore; backend: GeneratorBackend; pipeline: ReviewPipeline;
  gateway: LlmGateway; policy: Policy; repoPath: string; pr: PrReporter;
}
export interface RunSummary {
  runId: string; prs: Array<{ taskId: string; url: string | null }>;
  blocked: string[]; aborted?: 'budget' | 'wallclock' | 'kill';
}
export class BudgetExceededError extends Error {}

export class BudgetedGateway implements LlmGateway { // A6: bütçe gerçek usage üzerinden
  private total = 0;
  constructor(private readonly inner: LlmGateway, private readonly budgetUsd: number, private readonly onSpend: (usd: number) => void) {}
  get spent(): number { return this.total; }
  async complete<T>(req: { system: string; user: string; schema: { parse: (x: unknown) => T }; runId: string }): Promise<{ data: T; usage: TokenUsage }> {
    if (this.total >= this.budgetUsd) throw new BudgetExceededError(`Bütçe aşıldı: $${this.total.toFixed(2)} / $${this.budgetUsd}`);
    const r = await this.inner.complete(req);
    this.total += r.usage.costUsd;
    this.onSpend(this.total);
    return r;
  }
}

export class Orchestrator {
  private spendUsd = 0;
  constructor(private readonly deps: OrchestratorDeps) {}

  async run(tasksFile: string): Promise<RunSummary> {
    const { store, policy, repoPath } = this.deps;
    const startedAt = Date.now();
    const prevRuns = store.query({ type: 'RunStarted' });
    const runId = prevRuns.length > 0 ? prevRuns[prevRuns.length - 1].run_id : randomUUID();
    const policyHash = createHash('sha256').update(JSON.stringify(policy)).digest('hex').slice(0, 16);
    if (prevRuns.length === 0) {
      await store.append('RunStarted', runId, '-', 'orchestrator', { configSnapshot: { model: policy.llm.model, budgetUsd: policy.budgetUsd, policyHash } });
    }

    const budgeted = new BudgetedGateway(this.deps.gateway, policy.budgetUsd, (usd) => { this.spendUsd = usd; });
    const done = new Set([...store.query({ type: 'PRCreated' }), ...store.query({ type: 'TaskBlocked' })].map((e) => e.task_id));
    const tasks = (JSON.parse(readFileSync(tasksFile, 'utf8')) as unknown[]).map((t) => TaskSpecSchema.parse(t));
    const summary: RunSummary = { runId, prs: [], blocked: [] };
    const abort = async (reason: 'budget' | 'wallclock' | 'kill', taskId: string) => {
      await store.append('RunAborted', runId, taskId, 'orchestrator', { reason });
      summary.aborted = reason;
    };

    for (const task of tasks) {
      if (done.has(task.id)) continue;
      if (summary.aborted) break;
      if (this.spendUsd >= policy.budgetUsd) { await abort('budget', task.id); break; }
      if (existsSync(join(repoPath, '.devloop', 'STOP'))) { await abort('kill', task.id); break; }
      if ((Date.now() - startedAt) / 60000 > policy.wallClockMinutes) { await abort('wallclock', task.id); break; }

      await store.append('TaskPicked', runId, task.id, 'orchestrator', { taskSpec: task });
      const wt = join(repoPath, '..', `devloop-wt-${runId.slice(0, 8)}-${task.id}`);
      try {
        await runGit('git', ['worktree', 'add', wt, '-b', `devloop/${task.id}`], { cwd: repoPath });
        await this.executeTask(task, wt, runId, budgeted, summary);
      } finally {
        rmSync(wt, { recursive: true, force: true });
        await runGit('git', ['worktree', 'prune'], { cwd: repoPath }).catch(() => undefined);
      }
    }
    return summary;
  }

  /** Gate enforcement gövdesi (A2): her tur pipeline → fail ise feedback → sonraki tur. Tükenirse TaskBlocked, PR yok. */
  private async executeTask(task: ReturnType<typeof TaskSpecSchema.parse>, wt: string, runId: string, gateway: BudgetedGateway, summary: RunSummary): Promise<void> {
    const { store, policy } = this.deps;
    const taskEventId = store.query({ runId, taskId: task.id, type: 'TaskPicked' }).pop()!.event_id;
    let feedback: Finding[] = [];
    let lastResult: PipelineResult | null = null;
    let artEventId: string | null = null;
    let finalArtifact: Artifact | null = null;

    for (let tour = 1; tour <= policy.maxFixTours; tour++) {
      let artifact: Artifact;
      try {
        const base = await this.deps.backend.generate(task, {
          repoPath: wt, repoTree: '', repoFiles: [], lessons: '', feedback,
        });
        artifact = base;
      } catch (e) {
        if (e instanceof BudgetExceededError) {
          await store.append('RunAborted', runId, task.id, 'orchestrator', { reason: 'budget' });
          summary.aborted = 'budget';
          return;
        }
        throw e;
      }
      this.spendUsd = gateway.spent;
      if (this.spendUsd >= policy.budgetUsd && tour < policy.maxFixTours) { /* bir sonraki tur öncesi kontrol aşağıda */ }

      await applyArtifact(wt, artifact);
      await runGit('git', ['add', '-A'], { cwd: wt }); // untracked dahil (inceleme D)
      const diff = (await runGit('git', ['diff', '--cached', '--unified=0'], { cwd: wt })).stdout;
      artifact = { ...artifact, diff };

      const artEvent = await store.append('ArtifactProduced', runId, task.id, 'backend', { artifact, parentTaskEventId: taskEventId });
      artEventId = artEvent.event_id;
      finalArtifact = artifact;

      const reviewCtx: ReviewContext = { taskSpec: task, artifact, repoPath: wt, riskScore: 0 };
      lastResult = await this.deps.pipeline.run(reviewCtx);
      for (const v of lastResult.verdicts) {
        await store.append('StageVerdict', runId, task.id, 'pipeline', v);
      }
      await store.append('RiskScored', runId, task.id, 'risk-triage', {
        score: reviewCtx.riskScore, signals: reviewCtx.riskSignals ?? {}, policyVersion: String(policy.version),
        parentArtifactEventId: artEvent.event_id,
      });
      for (const f of lastResult.findings) {
        await store.append('FindingEmitted', runId, task.id, f.stage, { finding: f, parentArtifactEventId: artEvent.event_id });
      }
      if (lastResult.passed) break;
      feedback = lastResult.findings;
      if (this.spendUsd >= policy.budgetUsd) {
        await store.append('RunAborted', runId, task.id, 'orchestrator', { reason: 'budget' });
        summary.aborted = 'budget';
        return;
      }
    }

    if (!lastResult || !lastResult.passed || !finalArtifact || !artEventId) {
      if (!summary.aborted) {
        await store.append('TaskBlocked', runId, task.id, 'orchestrator', {
          reason: lastResult ? `gate-fail: ${lastResult.gateFailed}` : 'tur-tükendi', parentArtifactEventId: artEventId ?? undefined,
        });
        summary.blocked.push(task.id);
      }
      return; // A2: gate fail → commit/PR YOK
    }

    await runGit('git', ['commit', '-m', `${task.id}: ${finalArtifact.intent}`], { cwd: wt });
    const commitSha = ((await runGit('git', ['rev-parse', 'HEAD'], { cwd: wt })).stdout || '').trim() || null;
    const diffDigest = createHash('sha256').update(finalArtifact.diff).digest('hex');
    const pr = await this.deps.pr.openPr(`devloop/${task.id}`, `${task.id}: ${finalArtifact.intent}`,
      `${finalArtifact.intent}\n\ncommit: ${commitSha ?? '-'}\ndiffDigest: ${diffDigest}\n\n## Review bulguları (advisory — karar insanın)\n${
        lastResult.findings.map((f) => `- [${f.severity}] ${f.category} @ ${f.evidence.file}:${f.evidence.line ?? '-'} — ${f.suggestion ?? ''}`).join('\n') || '(bulgu yok)'}`,
      task.id);
    await store.append('PRCreated', runId, task.id, 'orchestrator', { url: pr.url, title: `${task.id}: ${finalArtifact.intent}`, commitSha, diffDigest });
    summary.prs.push({ taskId: task.id, url: pr.url });
  }
}

        decision, reason: opts.reason as never, note: opts.note,
        parentFindingEventIds: (opts.findings ?? '').split(',').filter(Boolean),
      });
      console.log('Karar kaydedildi.');
    });
  return program;
}

import { createHash } from 'node:crypto';
import type { VerdictStore } from '../store/store.js';
import type { LessonMemory } from '../memory/memory.js';

export interface CandidateLesson {
  lessonId: string; rule: string; scope: string; confidence: number;
  targetComponent: 'generator' | 'reviewer';
  parentDecisionEventIds: string[]; pattern: 'repeated-false-positive' | 'repeated-real-issue';
}

/** v1 deterministik aday üretimi (spec §6 faz 1). lessonId = sha256(pattern + sıralı karar IDs) — karar seti değişmedikçe sabit. */
export function generateCandidates(store: VerdictStore): CandidateLesson[] {
  const decisions = store.query({ type: 'HumanDecision' });
  const byFinding = new Map(store.query({ type: 'FindingEmitted' }).map((e) => [e.event_id, e.payload.finding.category]));

  const buckets = new Map<string, { reasons: Map<string, number>; decisionIds: string[] }>();
  for (const d of decisions) {
    const category = d.payload.parentFindingEventIds.map((id) => byFinding.get(id)).find(Boolean) ?? 'unknown';
    const b = buckets.get(category) ?? { reasons: new Map(), decisionIds: [] };
    b.reasons.set(d.payload.reason, (b.reasons.get(d.payload.reason) ?? 0) + 1);
    b.decisionIds.push(d.event_id);
    buckets.set(category, b);
  }

  const out: CandidateLesson[] = [];
  const makeId = (pattern: string, ids: string[]) =>
    createHash('sha256').update(`${pattern}:${[...ids].sort().join('|')}`).digest('hex').slice(0, 16);

  for (const [category, b] of buckets) {
    if ((b.reasons.get('false-positive') ?? 0) >= 2) {
      out.push({ pattern: 'repeated-false-positive', targetComponent: 'reviewer',
        lessonId: makeId('repeated-false-positive', b.decisionIds),
        rule: `Reviewer "${category}" kategorisinde tekrarlayan false-positive üretiyor. Bu kategoride bulgu raporlamadan önce kanıt eşiğini yükselt; şiddeti bir kademe düşürmeyi değerlendir.`,
        scope: 'review-rubric', confidence: 0.7, parentDecisionEventIds: b.decisionIds });
    }
    if ((b.reasons.get('real-issue-accepted') ?? 0) >= 2) {
      out.push({ pattern: 'repeated-real-issue', targetComponent: 'reviewer',
        lessonId: makeId('repeated-real-issue', b.decisionIds),
        rule: `"${category}" kategorisindeki bulgular tekrarlayan şekilde gerçek çıktı ve kabul edildi. Bu kategori güçlü sinyal; rubrikte önceliğini koru.`,
        scope: 'review-rubric', confidence: 0.8, parentDecisionEventIds: b.decisionIds });
    }
  }
  return out;
}

export async function confirmCandidate(store: VerdictStore, memory: LessonMemory, c: CandidateLesson) {
  const ev = await memory.appendLesson({
    lessonId: c.lessonId, rule: c.rule, scope: c.scope, confidence: c.confidence,
    status: 'active', targetComponent: c.targetComponent, parentDecisionEventIds: c.parentDecisionEventIds,
  });
  memory.render();
  return ev;
}
```
